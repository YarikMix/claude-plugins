# Удаление совместимого имени Figma Lookup

## Решение и авторизация

Пользователь согласовал удаление `figma-lookup` ответом «делай» на конкретное предложение: убрать копию, записи marketplace, генератор, проверки совместимости, локальные ссылки и перевести обязательное правило памяти на `figma-ops`.

## Подходы

Сохранение копии или нового alias оставляет ненужное сопровождение двух имён. Выбрано полное удаление старого плагина с явной инструкцией перехода на `figma-ops`. Это отменяет требование самостоятельного legacy root из спецификации первой итерации от 2026-10-22; прежние спецификации остаются историческими документами.

## Объём

- Удалить `plugins/figma-lookup` и `plugins/figma-ops/scripts/sync-compat.py`.
- Удалить legacy entry из Claude Code и Codex marketplace, обновить оба canonical manifest и entry до `1.4.1`.
- Исправить обе README: одно устанавливаемое имя, переход со старого плагина, актуальные команды проверки без sync.
- Сохранить проверки обнаружения canonical skill в обоих хостах, локальных ссылок, автономной установки из cwd с пробелами, всех 11 CLI операций, 12 help calls, 6 дополнительных CLI cases, 3 asset helper cases и его help call. Удалить только проверки генерации и равенства legacy-копии.
- Удалить два подтверждённых локальных legacy-симлинка, сохранив canonical ссылки; перевести активную заметку памяти и её индекс на `figma-ops`. Исторические заметки и содержимое сессий не переписывать.

## Ограничения и приёмка

Runtime, skill, references, API/MCP, credentials и макеты не изменяются. Новых зависимостей и migration runtime нет. Работа в отдельном worktree, без push/PR/merge. Тесты только с синтетическим transport, без чтения токена и доступа к Figma. Старые установки и вызовы теряют поддержку; переход описан в README. Полный unittest-набор canonical плагина проходит, `git diff --check` чистый, отдельный read-only reviewer проверяет итоговый diff. Фактическое обновление marketplace в живых клиентах не проверяется.
