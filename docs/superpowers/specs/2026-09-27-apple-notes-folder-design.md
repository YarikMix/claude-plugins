# Плагин `apple-notes-folder`: MCP-сервер Apple Notes, ограниченный одной папкой — дизайн

Дата: 2026-09-27

## Задача

Добавить в маркетплейс `yarikmix-plugins` третий плагин — `apple-notes-folder`: MCP-сервер, через который
агент Claude Code читает, ищет, создаёт, дописывает, правит и удаляет заметки Apple Notes **только в одной
папке**, заданной пользователем. Выйти за папку сервер не может ни одним инструментом. В заметки можно
вставлять картинки, вставленные пользователем в поле ввода Claude Code.

Официального MCP для Заметок у Apple нет. Существующие открытые серверы (например, `sweetrb/apple-notes-mcp`,
~40 тыс. строк, 83 инструмента, четыре канала доступа к Заметкам) не умеют ограничиваться папкой, а
доработать их дорого и тяжело поддерживать. Поэтому пишем свой маленький сервер. Документацию sweetrb
(`TECHNICAL_NOTES.md`) используем как справочник по особенностям AppleScript, код не переносим.

Плагин публичный: в репозитории нет имён папок, содержимого заметок и путей конкретного пользователя.

## Ограничение, которое сервер не снимает

Разрешение macOS «Автоматизация → Заметки» выдаётся приложению-терминалу целиком (iTerm, Terminal и т. п.).
Любой процесс из этого терминала может управлять Заметками в обход сервера, например `osascript` из Bash.
Плагин ставит хук, который перекрывает очевидный обход (раздел «Хук на Bash»), но намеренный обход —
скрипт в отдельном файле, зашифрованная строка, запуск через другой язык — хук не ловит. README говорит это
прямо. Ограничить доступ одной папкой на уровне macOS нельзя.

## Устройство

```
plugins/apple-notes-folder/
  .claude-plugin/plugin.json   # userConfig, mcpServers, hooks
  hooks/hooks.json             # PreToolUse на Bash
  src/
    server.ts                  # регистрация инструментов (MCP SDK + zod)
    scope.ts                   # поиск папки при старте, хранение её id
    notes.ts                   # AppleScript-шаблоны и исполнитель osascript
    markdown.ts                # Markdown → HTML (marked), HTML → Markdown (turndown)
    images.ts                  # заглушки картинок, проверка и встраивание новых
    hook.ts                    # логика хука
  dist/server.js, dist/hook.js # собранные esbuild, закоммичены
  scripts/live-check.mjs       # ручная проверка на живых Заметках
  test/                        # vitest
  package.json, package-lock.json, README.md, LICENSE (MIT)
```

- Реализация: Node ≥ 20, TypeScript, `@modelcontextprotocol/sdk`, `zod`, `marked`, `turndown`; сборка
  `esbuild` в один файл. Зависимости закреплены `package-lock.json`. Во время работы сервер ничего не
  скачивает и не делает сетевых запросов.
- Воспроизводимость сборки: `npm ci && npm run build` даёт побайтно тот же `dist/`, что закоммичен.
  Проверка — скрипт `npm run verify-build` (сборка во временную папку и сравнение). Читать нужно исходники
  и lock-файл, сборку сверяет скрипт.
- Запись в `.claude-plugin/marketplace.json` по образцу `selectel-ops`; строка в таблице плагинов корневого
  README.

### Настройка

В `plugin.json`:

```json
"userConfig": {
  "folder": {
    "type": "string",
    "title": "Папка Заметок",
    "description": "Имя единственной папки Apple Notes, с которой может работать агент",
    "required": true
  }
},
"mcpServers": {
  "apple-notes-folder": {
    "command": "node",
    "args": ["${CLAUDE_PLUGIN_ROOT}/dist/server.js"],
    "env": { "NOTES_FOLDER": "${user_config.folder}" }
  }
}
```

Claude Code спрашивает имя при включении плагина и не принимает пустое значение; сменить —
`/plugin configure apple-notes-folder@yarikmix-plugins`. Значения по умолчанию нет.

### Поиск папки (`scope.ts`)

- При старте сервер ищет среди всех папок всех аккаунтов папку с именем ровно `NOTES_FOLDER`.
- Ровно одна → запоминает её id (`x-coredata://…/ICFolder/p…`), дальше работает только по id.
- Ноль или несколько (одинаковое имя в разных аккаунтах или вложенная папка с тем же именем) → сервер
  запускается, но каждый инструмент возвращает ошибку: что не так (не найдена / найдено N, в каких
  аккаунтах) и что поможет (`/plugin configure`, переименование папки). Упавший молча сервер хуже.
- Пустая `NOTES_FOLDER` → та же ошибка настройки.
- Переименование папки после старта не ломает работу (id прежний); после перезапуска сервера — ошибка
  «не найдена».

## Инструменты

| Инструмент | Вход | Что делает |
|---|---|---|
| `notes_list` | `limit` (1–200, по умолчанию 50), `offset` | заметки папки: id, заголовок, дата изменения; новые сверху |
| `notes_search` | `query`, `limit` (1–50, по умолчанию 20) | заметки папки, где `query` есть в заголовке или тексте (без учёта регистра) |
| `notes_read` | `id` | заметка целиком в Markdown; первая строка — заголовок `# …` |
| `notes_create` | `title`, `markdown` | новая заметка в папке; возвращает id |
| `notes_append` | `id`, `markdown` | дописать в конец, не пересобирая существующий текст |
| `notes_update` | `id`, `markdown` | заменить текст целиком (формат как у `notes_read`, с заголовком) |
| `notes_delete` | `id` | удалить; заметка уходит в «Недавно удалённые» |

Картинки — не отдельный инструмент: `![подпись](путь)` в `markdown` у `create`, `append`, `update`.
Переноса между папками, работы с подпапками, тегов, таблиц, чек-листов и вложений-файлов нет.

## Граница папки (`notes.ts`)

- Все скрипты — постоянные шаблоны в коде. Данные в текст скрипта не подставляются никогда: короткие
  значения (id заметки, id папки, запрос поиска) идут аргументами `on run argv`, HTML тела — временным
  файлом, путь к которому передаётся аргументом. Внедрить команду AppleScript через заголовок, текст или
  запрос невозможно.
- Временный файл: `mkdtemp` в `os.tmpdir()`, права `0600`, удаляется после вызова в любом исходе.
- Список и поиск работают от `notes of folder id <id папки>` — заметки других папок в выборку не попадают.
- Каждый скрипт, принимающий id заметки, первым делом сверяет `id of container of note id <id>` с id папки;
  при несовпадении — ошибка «заметка вне разрешённой папки» **без названия и содержимого** этой заметки.
  Проверка и действие — в одном скрипте.
- Подпапки разрешённой папки в границу не входят (у их заметок другой `container`). Заметка в «Недавно
  удалённых» автоматически оказывается снаружи.
- Заметки под паролем (`password protected`) не читаются и не меняются — ошибка «заметка защищена паролем».
- `osascript` запускается через `execFile` (без shell), таймаут 30 с на вызов, `maxBuffer` 64 МБ; внутри
  скрипта `with timeout of 30 seconds`.

## Markdown и картинки

### Чтение

- HTML тела → Markdown (turndown): заголовки, абзацы, жирный, курсив, зачёркнутый, ссылки, списки (включая
  вложенные), код.
- Заметки хранят вставленные картинки внутри HTML как base64 `data:`-URI; одна заметка легко превышает
  10 МБ и рвёт соединение MCP (наблюдение sweetrb). Поэтому картинки заменяются заглушками
  `![картинка N](note-image:N)` по порядку в тексте; base64 агенту не отдаётся.
- Ответ длиннее 200 000 символов обрезается с явной пометкой в конце.

### Запись

- Markdown → HTML (marked) в разметке, которую принимают Заметки (`<div>`, `<h1>`–`<h3>`, `<b>`, `<i>`,
  `<ul>/<ol>/<li>`, `<a>`, `<pre>/<code>`). Сырой HTML во входном Markdown экранируется как текст.
- `notes_create`: тело = заголовок первой строкой + текст. Какой именно тег даёт Заметкам заголовок так,
  чтобы `name` заметки совпал с `title`, — проверяется первым шагом живой проверки.
- `notes_update`: заглушки `note-image:N` заменяются исходными картинками из текущего тела (тело читается
  в том же вызове инструмента). Заглушка, которой нет в новом тексте, — картинка удаляется; это
  задокументированное поведение. Номер, которого не было в исходной заметке, — ошибка.
- `notes_append`: новый HTML дописывается к текущему телу как есть; существующие картинки и оформление не
  пересобираются.

### Новые картинки

`![подпись](путь)` в записи встраивает файл как `data:`-URI в HTML. Путь проходит проверки:

1. После `realpath` файл лежит внутри `/private/tmp/claude-<uid>/` (uid — текущего пользователя). Туда
   Claude Code кладёт картинки, вставленные в поле ввода, и scratchpad сессии.
2. Сам путь не символическая ссылка; это обычный файл.
3. Размер не больше 10 МБ.
4. Формат по первым байтам: PNG, JPEG, GIF, HEIC, WebP. Расширение не учитывается.

Нарушение любой проверки — ошибка с причиной; заметка не меняется.

Встраивание через `data:`-URI — первый шаг живой проверки: по данным sweetrb, картинки через AppleScript
добавляются ненадёжно (могут попасть во вложения, но не в текст). Если на macOS 26.5 встраивание не
отображается в тексте, запасной путь — `make new attachment` в конец заметки; тогда `![](путь)` в середине
текста даёт ошибку с объяснением, а картинки дописываются только в конец. Какой путь выбран — фиксируется
в README по итогам проверки.

## Хук на Bash

`hooks/hooks.json`: `PreToolUse`, `matcher: "Bash"`, команда `node ${CLAUDE_PLUGIN_ROOT}/dist/hook.js`.

- Хук читает JSON вызова со stdin и отклоняет команду (`permissionDecision: "deny"`), если в ней
  одновременно есть (без учёта регистра):
  - запуск скриптов: `osascript`, `applescript`, `jxa`, `NSAppleScript`, `ScriptingBridge`;
  - и упоминание Заметок: `Notes`, `com.apple.Notes`, `NoteStore`, `group.com.apple.notes`.
- Отдельно отклоняется `sqlite3` вместе с `NoteStore`.
- Причина отказа говорит агенту использовать инструменты `notes_*`.
- Всё остальное пропускается без вывода.

## Ошибки

- Ошибка настройки (папка не задана / не найдена / неоднозначна) — в ответе каждого инструмента.
- Нет разрешения на автоматизацию (`-1743`) — объяснение, где выдать разрешение.
- Таймаут записи — «изменение могло примениться; перечитайте заметку перед повтором».
- Заметка не найдена (удалена, неверный id) — отдельная ошибка, не путается с «вне папки».
- Ошибки не содержат текста и названий заметок вне папки.

## Тесты

### Автотесты (vitest, только для разработки)

- **Конвертер.** Markdown → HTML → Markdown сохраняет заголовки, списки (в т. ч. вложенные), ссылки, код;
  сырой HTML экранируется. Заглушки `note-image:N` в `update` возвращают исходные картинки на место;
  удалённая заглушка убирает картинку; несуществующий номер — ошибка.
- **Картинки.** Отказ: файл вне `/private/tmp/claude-<uid>/`; символическая ссылка (включая ссылку
  изнутри папки наружу); текст с расширением `.png`; файл больше 10 МБ. Пропуск: настоящие PNG, JPEG, HEIC.
- **Граница папки** на подставном исполнителе `osascript`: каждый шаблон, принимающий id заметки, содержит
  проверку `container`; ни один шаблон не зависит от входных данных (шаблоны — константы, данные только в
  argv); ответ «вне папки» не содержит названия заметки.
- **Поиск папки.** Ноль, одна, несколько найденных; пустая `NOTES_FOLDER`.
- **Хук.** Отказ: `osascript -e 'tell application "Notes" …'`, `osascript -l JavaScript … Notes`,
  `sqlite3 …/NoteStore.sqlite`. Пропуск: `git log`, `grep Notes README.md`, `osascript -e 'display dialog "hi"'`.
- **Сборка.** `npm run verify-build` проходит.

### Живая проверка (`scripts/live-check.mjs`, вручную)

Пользователь согласился на тестовые папки в iCloud: они ненадолго появятся на всех его устройствах, а
удалённые из них заметки пролежат в «Недавно удалённых» 30 дней.

1. Скрипт создаёт две тестовые папки с уникальным суффиксом: «разрешённую» и «чужую»; в «чужой» — заметку
   с уникальным словом. Реальные папки не затрагиваются.
2. Встраивание картинки через `data:`-URI и заголовок `notes_create` — решение из раздела «Запись».
3. В «разрешённой» — все семь инструментов, включая картинку из `/private/tmp/claude-<uid>/` и сохранение
   картинок при `update`.
4. На «чужую» заметку `read`, `append`, `update`, `delete` получают «вне разрешённой папки»; `search` по
   уникальному слову из «чужой» возвращает 0 результатов (печатается сырое число).
5. Хук: агент пробует прочитать «чужую» заметку через `osascript` в Bash и получает отказ.
6. Время `notes_list` и `notes_search` на папке порядка тысячи заметок — фиксируется в README.
7. Обе тестовые папки удаляются.

## После реализации

- Пользователь удаляет плагин `apple-notes@apple-notes-mcp` и его маркетплейс, чтобы 83 инструмента
  sweetrb не работали параллельно с новым сервером.
- Инструменты удаления и перезаписи (`notes_delete`, `notes_update`) не добавляются в автоматически
  разрешённые — Claude Code спрашивает подтверждение на каждый вызов.

## Вне рамок

Несколько папок, подпапки, перенос между папками, теги, таблицы, чек-листы, вложения-файлы, аудио, прямое
чтение базы Заметок (нужен полный доступ к диску), любые сетевые функции.
